# 📊 Pesquisa de Atendimento ao Cliente em Python

Este projeto consiste em um programa desenvolvido em Python para coletar, validar e exibir o retorno de uma pesquisa de satisfação de atendimento ao cliente, simulando um cenário real de coleta de dados.

## 🚀 Funcionamento do Programa

O script utiliza estruturas de repetição para entrevistar exatamente **50 pessoas**. Para cada participante, são coletados os seguintes dados:
- Nome
- Idade
- Opinião sobre o atendimento, baseada no menu:
  - `1`: EXCELENTE
  - `2`: BOM
  - `3`: RUIM

Ao final das 50 entrevistas, o programa exibe em formato de relatório:
- **a)** A quantidade total de respostas "EXCELENTE"
- **b)** A quantidade total de respostas "RUIM"

## 🛠️ Tecnologias e Conceitos Aplicados

- **Lógica de Programação** e manipulação de variáveis/contadores.
- **Estrutura `for`**: Para garantir o limite exato de 50 iterações de forma automatizada.
- **Estrutura `while`**: Utilizada como uma camada de segurança (tratamento de erros) para impedir o avanço caso o usuário digite uma opção inválida.
- **Condicionais `if/elif`**: Para a filtragem lógica dos dados coletados.
